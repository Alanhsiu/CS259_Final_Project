# Test Vectors for INT8 Matrix Multiply

Generated by `generate_test_vectors.py` using `np.random.seed(42)`.

## Size subfolders

| Folder | Contents |
|--------|----------|
| `size_4/` | 4×4 systolic array; 10 random tiles + 3 edge cases |
| `size_8/` | 8×8 systolic array; 10 random tiles + 3 edge cases |
| `size_16/` | 16×16 systolic array; 10 random tiles + 3 edge cases |

Each size folder contains two subfolders:
- `random/` — 10 random tiles: `tile_00_*` … `tile_09_*`
- `edge/`   — 3 edge cases: `zeros_*`, `identity_*`, `maxval_*`

## File format

For an N×N tile there are three files:

| Suffix | Type | Lines | Chars/line |
|--------|------|-------|------------|
| `_A.hex` | INT8 | N² | 2 (two's complement) |
| `_B.hex` | INT8 | N² | 2 (two's complement) |
| `_C_expected.hex` | INT32 | N² | 8 (two's complement) |

Values are stored in **row-major** order (row 0 first).

Examples: `-1` (INT8) → `ff`; `-128` → `80`; `127` → `7f`; `-1` (INT32) → `ffffffff`

## Edge cases (all sizes)

| File prefix | Description |
|-------------|-------------|
| `zeros` | All-zeros A and B → all-zeros C |
| `identity` | Identity × Identity = Identity |
| `maxval` | All-127 A and B → INT32 overflow stress test |

## Verilog `$readmemh` usage

```verilog
// 4×4 tile
logic signed [7:0]  A_4 [0:15];
logic signed [7:0]  B_4 [0:15];
logic signed [31:0] C_4 [0:15];
initial begin
    $readmemh("size_4/random/tile_00_A.hex",          A_4);
    $readmemh("size_4/random/tile_00_B.hex",          B_4);
    $readmemh("size_4/random/tile_00_C_expected.hex", C_4);
end

// 8×8 tile
logic signed [7:0]  A_8 [0:63];
logic signed [7:0]  B_8 [0:63];
logic signed [31:0] C_8 [0:63];
initial begin
    $readmemh("size_8/random/tile_00_A.hex",          A_8);
    $readmemh("size_8/random/tile_00_B.hex",          B_8);
    $readmemh("size_8/random/tile_00_C_expected.hex", C_8);
end

// 16×16 tile
logic signed [7:0]  A_16 [0:255];
logic signed [7:0]  B_16 [0:255];
logic signed [31:0] C_16 [0:255];
initial begin
    $readmemh("size_16/random/tile_00_A.hex",          A_16);
    $readmemh("size_16/random/tile_00_B.hex",          B_16);
    $readmemh("size_16/random/tile_00_C_expected.hex", C_16);
end
```

Row `r`, column `c` is at index `r*N + c`.
